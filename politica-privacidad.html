PRIVACIDAD Y TRANSPARENCIA

POLÍTICA DE PRIVACIDAD

Aquí explicamos, de forma directa, qué información utiliza Launcher Remastered, para qué se usa y qué datos no solicitamos.

SIN CUENTA OBLIGATORIA EN LA WEB SKINS: NICK + IMAGEN SIN CONTRASEÑAS MICROSOFT

PROYECTO INDEPENDIENTE Y NO OFICIAL. Launcher Remastered no es el launcher oficial de Minecraft y no está afiliado, patrocinado, aprobado ni respaldado por Mojang Studios o Microsoft.

QUÉ DATOS USAMOS

La web no exige crear una cuenta y no solicita contraseñas, documentos de identidad ni información financiera.

Para la función de skins en multijugador se utiliza únicamente el nick del usuario y la imagen/skin asociada.

PARA QUÉ SE USAN

El nick y la imagen se utilizan para que usuarios de Launcher Remastered puedan visualizar sus skins entre sí en multijugador.

No se usan para publicidad, venta de datos ni para obtener acceso a cuentas de Microsoft.

MICROSOFT Y PREMIUM

La función Premium está pensada para utilizar el flujo oficial de autenticación de Microsoft.

Launcher Remastered no está diseñado para recibir ni almacenar la contraseña o las credenciales de Microsoft.

SITIO Y SERVICIOS EXTERNOS

El alojamiento puede registrar datos técnicos básicos, como IP, navegador, sistema operativo, fecha, hora y errores, para entregar y proteger el sitio.

Al usar contenido o enlaces de YouTube, GitHub, TikTok, PayPal, Microsoft u otros servicios, también aplican las políticas de esos proveedores.

COOKIES Y ANALÍTICA

La web no instala cookies publicitarias propias. Si se habilita una herramienta de analítica, puede utilizar cookies o datos técnicos de medición conforme a su propia política.

Las funciones no esenciales deben respetar los requisitos de consentimiento aplicables.

CONSERVACIÓN Y SEGURIDAD

Los datos de skins se conservan solo mientras sean necesarios para la función multijugador o hasta que proceda su revisión o eliminación.

Se aplican medidas razonables de seguridad, aunque ningún sistema conectado a Internet puede garantizar riesgo cero.

SOFTWARE, DESCARGAS Y ENLACES

Obtén Launcher Remastered únicamente desde los canales oficiales del proyecto y revisa siempre el origen de cualquier archivo. Los enlaces a Minecraft o Microsoft dirigen a servicios de sus respectivos titulares.

Launcher Remastered no distribuye, vende ni sustituye Minecraft. El acceso al juego debe realizarse de forma legítima mediante los canales correspondientes.

TUS DERECHOS

Cuando la legislación aplicable lo permita, puedes solicitar acceso, corrección, actualización o eliminación de los datos personales asociados a las funciones del proyecto.

Las solicitudes deben realizarse mediante los canales oficiales de ChrisCode+ o del proyecto, evitando publicar datos sensibles en espacios públicos.
