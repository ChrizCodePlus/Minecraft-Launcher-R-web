MINECRAFT LAUNCHER REMASTERED - WEB 4.0.0

Creado para ChrisCode+.

ARCHIVOS PRINCIPALES
- index.html
- politica-privacidad.html
- css/style.css
- js/app.js
- assets/
- downloads/

USO
1. Abre index.html en tu navegador.
2. Para publicar, sube toda la carpeta a Netlify, GitHub Pages o tu hosting.
3. Mantén las descargas dentro de downloads/ usando estos nombres:
   - Minecraft-Launcher-Remastered-Windows.exe
   - MinecraftLauncherR-linux-x64.zip
   - INSTRUCCIONES_LINUX.txt
4. El ZIP de Linux incluye INSTRUCCIONES_LINUX.txt y también existe una copia suelta para descargar desde la web.
5. Los hashes públicos están en downloads/SHA256SUMS.txt.

- CSS del changelog integrado en style.css.
