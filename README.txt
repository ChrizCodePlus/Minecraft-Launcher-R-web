- js/update-accordion.js
- assets/
- downloads/

USO
1. Abre index.html en tu navegador.
2. Para publicar, sube toda la carpeta a Netlify o a tu hosting.
3. Mantén las descargas dentro de downloads/ usando estos nombres:
   - Minecraft-Launcher-Remastered-Windows.exe
   - MinecraftLauncherR-linux-x64.zip
   - INSTRUCCIONES_LINUX.txt
4. El ZIP de Linux incluye INSTRUCCIONES_LINUX.txt. Tambien se deja una copia suelta del .txt en downloads/ para mostrarla o descargarla desde la web.
5. El modal de actualizacion muestra lo nuevo, lo agregado, lo mejorado y lo corregido.
5. Los hashes públicos están en downloads/SHA256SUMS.txt.

NOTA
El sitio usa HTML, CSS y JavaScript puro; no requiere instalaciones ni dependencias.

DESCARGAS INCLUIDAS
- Windows: downloads/Minecraft-Launcher-Remastered-Windows.exe
- Linux: downloads/MinecraftLauncherR-linux-x64.zip
- Instrucciones Linux: downloads/INSTRUCCIONES_LINUX.txt
