DESCARGAS
Este paquete web NO incluye los instaladores de Windows ni Linux y tampoco incluye archivos SHA.
La carpeta downloads/ conserva únicamente:
- INSTRUCCIONES_LINUX.txt

Antes de publicar nuevos instaladores, enlázalos desde un canal oficial del proyecto y actualiza los botones de la sección Descargas.

PRIVACIDAD
La política explica de forma resumida el uso del nick y la imagen/skin para la función multiplayer de usuarios de Launcher Remastered, el uso de servicios externos y la condición independiente del proyecto.
